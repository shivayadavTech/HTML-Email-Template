<h1>HTML Email Templates Collection</h1>
This repository features a curated collection of professional, high-performance email templates designed for modern marketing needs. Each template is built using clean HTML Table structures to ensure 100% compatibility across all major email platforms.<hr><br/><br/>

<h2>🚀 Platform Compatibility</h2>
These templates work smoothly on all platforms given the niche:

ESPs: Mailchimp, Klaviyo, HubSpot, SendGrid, and Brevo.

Email Clients: Fully optimized for Microsoft Outlook (Desktop & Web), Gmail, Apple Mail, and Yahoo.

Devices: Mobile-responsive design that scales perfectly on iPhone, Android, and Tablets.<hr><br/>

<h2>✓ Key Technical Features</h2>
Outlook-Ready: Uses specialized MSO conditional code to prevent layout breaking in Outlook.

Table-Based Layout: Hand-coded for maximum stability and email deliverability.

Inline CSS: All styles are inlined for better rendering and to avoid being marked as spam.

Ready-to-Use: Just copy the code and swap the images/text.<hr>
